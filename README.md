# LinguiMundi - Frontend React

Este es el módulo frontend del proyecto LinguiMundi, desarrollado utilizando **React JS** mediante CDN y Babel para el renderizado.

## Características
- Componente funcional con Hooks (`useState`).
- Conexión al backend de Node.js mediante `fetch` API.
- Interfaz de Login y Dashboard.
- Código comentado siguiendo estándares.

## Cómo ejecutar
1. Asegúrate de que el backend en Node.js esté corriendo en el puerto 8080.
2. Abre el archivo `index.html` en tu navegador web.
